# LEKGS — Página web basada en la maqueta

## Estructura
- `index.html`: contenido y estructura de la página.
- `css/styles.css`: diseño visual, responsive y componentes.
- `js/script.js`: menú móvil, filtros de noticias, búsqueda y formulario.

## Cómo abrirla
1. Descarga y descomprime la carpeta.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. No necesita servidor para la primera prueba.

## Importante
Las fotografías usadas en esta primera versión son imágenes externas de demostración. Para que el proyecto quede completamente propio, reemplázalas por las fotografías reales del colegio en una carpeta `img/` y cambia los `src` del HTML.

## Para llevarla a producción
- Conectar el formulario a un backend o servicio de correo.
- Crear páginas/artículos individuales para cada noticia.
- Añadir una base de datos si las noticias, usuarios o eventos se van a administrar desde un panel.
- Configurar dominio, HTTPS y hosting.
